# cosmo-tokens — 設計値の抽出・同期

設計リファレンスから確定値を 1:1 で写す機械作業。**モデルはこのスキルでは決めず、`token-extractor` サブエージェント（Haiku4.5 に固定）へ委譲する**ことで一元化する。

## 手順
1. **対象と出力先を確定**（メイン側の下準備）：何を抽出するか（例：カラートークン全部 / Skills セクションのチップ / density の範囲）、どのファイルへ書くかを決める。原典は `design/README.md`（フルスペック）と `design/Cosmic_Portfolio.dc.html`（実装値）。
2. **`token-extractor` に委譲**：Agent ツールで `subagent_type: token-extractor` を呼び、「抽出対象・出力先・原典パス」を渡す。値の判断は不要、1:1 転記と一意な変換だけを依頼する。
3. **差し戻しを処理**：原典の食い違い・曖昧な単位など、エージェントが差し戻した点だけをメイン（Opus）で判断して確定させ、再度 token-extractor に転記させる。
4. 必要なら `cosmo-qa` で「スペック値と実装値の一致」を検査する。

## 注意
- このスキルで新しい値を発明しない。原典にない値が要るなら、それは設計判断（Opus、場合により Fable）であって抽出作業ではない。
- 出力には出典 `file:line` を残す方針を維持する。
