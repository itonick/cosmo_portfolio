# cosmo-build — 型に沿った実装の量産

確立したパターンをなぞる実装。**モデルはこのスキルでは決めず、`builder` サブエージェント（Sonnet5 に固定）へ委譲する**。

## 使う前の前提（机を整える）
着手前に次が揃っていること。無ければ先にメイン（Opus、必要なら Fable）で確定させる：
- スタック / ファイル構成が決まっている。
- なぞるべき既存パターン（先行実装 or 明示スペック）がある。
- 使うトークン/定数が `cosmo-tokens` で抽出済み。

## 手順
1. **作業を型に分解**（メイン側の下準備）：実装対象を「既存パターンの適用」に落とし込み、参照先・出力先・受け入れ条件を明文化する。
2. **`builder` に委譲**：Agent ツールで `subagent_type: builder` を呼び、「なぞるパターン・対象・トークン・`design/README.md` の該当箇所」を渡す。
3. **差し戻しを処理**：builder が「新しい設計判断が要る」と止めたら、その判断はメイン（Opus、全体波及なら Fable 切替提案）で行い、確定後に再委譲する。
4. **検査とレビュー**：実装後は `cosmo-qa`（checker/Haiku）で機械検査、`cosmo-review`（reviewer/Opus）で判断レビュー。

## 注意
- builder に判断させない。判断が必要になった時点で上位へ返すのが正しい動き。
